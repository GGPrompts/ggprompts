01 // Overview

Project Overview

A full-stack resource directory that uses AI to help veterans find the support they need. Instead of scrolling through endless lists, veterans can describe their situation in natural language and get matched with relevant resources across employment, training, housing, and legal categories. Built with Django on the backend and React on the frontend, deployed on Vercel.

06 // Lessons Learned

Lessons Learned

01

Building for Social Impact

Technical skills matter most when they solve real problems. Building for veterans taught the importance of accessibility, clear language, and reducing friction in critical moments of need.

02

Resource Directory Patterns

Categorization, tagging, and search are deceptively complex. Resources need multiple classification axes, and users search in unpredictable ways. AI search fills the gap between structured data and human intent.

03

AI-Enhanced Search for Real-World Needs

Keyword search fails when users do not know the right terminology. A veteran searching "I need help paying rent" should find housing assistance even if no resource is tagged with those exact words. AI bridges that gap.
