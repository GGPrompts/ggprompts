Project Overview

A kanban board purpose-built for orchestrating AI agents. Unlike traditional project boards, each column can have an AI agent assigned to it with custom step prompts. Cards auto-advance through the pipeline as agents complete their work -- from planning to implementation to review.

Built as both a full-featured web application (Next.js with a Cyberpunk Terminal / Mission Control aesthetic) and a terminal TUI (Go with Bubbletea), the project demonstrates dual-platform development with shared conceptual architecture but platform-native implementations.

Lessons Learned

  • Dual-platform development (Web + TUI) -- sharing conceptual architecture while building platform-native UIs with completely different tech stacks
  • Drag-and-drop in both paradigms -- @dnd-kit for the web, mouse events in Bubbletea for the terminal, same mental model
  • AI agent workflow visualization -- making the invisible work of AI agents visible through pipeline columns and status indicators
  • Cyberpunk aesthetic as functional design -- glass effects and neon accents are not just decoration, they create visual hierarchy in information-dense dashboards
