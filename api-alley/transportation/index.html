🚢 VESSEL_TRACKING · AIS · maritime
🚢
Ship Tracking — AIS Data
aishub.net · Global maritime AIS network
PROXY REQ.
🚢

Needs a server-side proxy

AIS vessel tracking APIs (AISHub, MyShipTracking, MarineTraffic) do not send Access-Control-Allow-Origin headers, so they cannot be fetched directly from a browser. You need a proxy to relay requests.

MarineTraffic.com ↗ VesselFinder ↗ ShipFinder ↗ aisstream.io ↗
To enable in production: deploy a lightweight proxy endpoint (GET /proxy/ais?mmsi=ALL) that forwards to aishub.net/api and adds the CORS header. AISHub is free for non-commercial use with data sharing.
